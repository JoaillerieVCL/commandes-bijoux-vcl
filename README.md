# Commandes Bijoux — Joaillerie VCL

Application web de prise de commandes bijoux avec liens clients partageables.

## Usage atelier
1. Ouvrir le site
2. Créer une commande (infos connues + champs à demander au client)
3. Copier le lien ou l'envoyer par WhatsApp

## Usage client
Le client ouvre le lien, complète métal, grandeur, couleur, etc., puis renvoie le résumé / lien de confirmation.
